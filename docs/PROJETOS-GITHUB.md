- **O que é:** Site profissional para empresa de engenharia e serviços elétricos, desenvolvido para um cliente. Agendamento de visitas com integração direta à API do Google Calendar no Next.js (sem VPS ou n8n), notificações via WhatsApp/E-mail e contrato digital.
